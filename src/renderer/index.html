    Setup & help

    Everything needed to make notifications, Hyprland floating/always-on-top, and the app menu behave. The one-line installer can do most of this for you.

    Notifications

    checking…

    Checking for a notification daemon…

    sudo pacman -S --needed mako
    mako &

    No daemon = bee puns still appear as in-app toasts, but never as desktop notifications. On other distros try dunst, swaync or fnott. Add mako to your compositor autostart so it survives reboots.

    Want a notification for every chaos event, not just puns? Enable Notify on every chaos event in Settings → App.

    Hyprland window rules

    Lua · 0.57+

    Hyprland tiles new windows, so BEE Timer needs a float + pin rule to stay a floating always-on-top widget.

    hl.window_rule({
    match = { class = "bee-timer" },
    float = true,
    size = "400 320",
    pin = true,
})
    Older Hyprland (hyprland.conf syntax) 
    windowrulev2 = float,class:^(bee-timer)$
windowrulev2 = size 400 320,class:^(bee-timer)$
windowrulev2 = pin,class:^(bee-timer)$

    Add the block to your Hyprland config, then run hyprctl reload. If a dotfiles framework generates your config, put it in your user override file instead. The installer can also add it for you (after asking).

    Installed files

    optional installer
    • ~/.local/bin/bee-timerlauncher command
    • ~/.local/opt/bee-timer/appunpacked app
    • ~/.local/share/applications/bee-timer.desktopapp menu entry

    Installed with the one-line script? These are the exact paths it writes (AppImage builds don't use them). Your config lives at ~/.config/BEE Timer/config.json.

    Uninstall

    curl -fsSL https://raw.githubusercontent.com/nu-code-dev/bee-timer/main/install.sh | bash -s -- --uninstall

    Removes the app, launcher, menu entry and icon, and the BEE Timer Hyprland rule block. Leaves your settings file alone.
